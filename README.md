# 🛒 Sistema de Desconto Progressivo

Programa em Python desenvolvido para simular o cálculo de descontos progressivos em compras de uma loja online, aplicando percentuais ajustados de acordo com o valor total gasto.

---

## 📌 Sobre o Projeto

O sistema solicita o valor total de uma compra via terminal, valida a entrada do usuário e aplica automaticamente a regra de desconto correspondente.

### ⚙️ Regras de Desconto:
* **Compras abaixo de R$ 200,00:** 5% de desconto
* **Compras entre R$ 200,00 e R$ 299,99:** 10% de desconto
* **Compras a partir de R$ 300,00:** 15% de desconto

---

## 🚀 Funcionalidades

- **Tratamento de Entradas:** Aceita vírgula ou ponto para casas decimais.
- **Validação de Dados:** Impede o processamento de valores negativos ou zerados.
- **Tratamento de Exceções (`try/except`):** Captura erros de digitação de texto no lugar de números.
- **Resumo Detalhado:** Exibe o valor original, o percentual aplicado, o valor economizado e o valor final.
